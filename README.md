# commands-archive

### Mở Terminal để chạy file cài đặt
```
curl -s "https://raw.githubusercontent.com/matechios/commands-archive/main/<#tên file#>?v=$(date +%s)" | bash
```
### Danh sách tên file cài đặt
1. Setup base project `make-project.sh`
2. Weekly report `weekly-report-installer.sh`
3. Firebase App Distribution `fb-build-installer.sh`
